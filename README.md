# E-Commerce Sales Analysis Dashboard

## Overview
Developed an interactive E-Commerce Sales Dashboard using Microsoft Excel to analyze sales performance, customer purchasing behavior, and revenue trends. The dashboard provides business insights through charts, KPI metrics, and interactive filters for better decision-making.

## Tools & Technologies
- Microsoft Excel

## Dashboard Features
- Total Revenue Analysis
- Total Orders Tracking
- Average Customer Spending
- Order Delivery Time Analysis
- Revenue by Category
- Revenue by Occasion
- Revenue by Months
- Top Products by Revenue
- Top Cities by Orders
- Interactive Filters and Slicers

## Key Insights
- Analyzed revenue trends across different occasions and categories
- Identified top-performing products and cities
- Evaluated customer spending patterns
- Monitored order delivery performance
- Created interactive dashboards for business reporting
